# Étude de cas : CycleNova, e-commerce d'équipements de cyclisme

Épreuve blanche de Data Analyst, réalisée par BONI Loïc.

Ce dépôt contient les mêmes fichiers que le dossier de rendu partagé sur Google Drive, à l'exception de la vidéo de présentation (BC04, partie 5).

## Contenu

- `Epreuve_Blanche_CycleNova_BONI_Loic.docx` : le document de rendu rempli (réponses aux QCM, aux questions ouvertes, liens vers les livrables).
- `BC01 - Collecte et traitement des données/` : notebook SQL, requête SQL BigQuery et captures d'écran des contrôles.
- `BC02 - Statistiques/` : notebook d'analyse exploratoire et de statistiques.
- `BC03 - Machine Learning/` : notebook de modélisation (prédiction des retours).
- `BC06 - Dashboard/` : export PDF du tableau de bord Looker Studio et requête SQL utilisée comme source.

## Ce qui n'est pas dans ce dépôt

- Les deux présentations (BC01 et BC04) : ce sont des fichiers Google Slides, leurs liens sont dans le document de rendu.
- La vidéo de présentation du projet (BC04, partie 5) : le lien est dans le document de rendu.
- Les fichiers de données du sujet (`produits.csv`, `ventes.csv`, `prix_concurrents.csv`) : les notebooks les cherchent dans un dossier `DONNEES` placé à côté des dossiers BC.

Les données sont fictives : aucune donnée de client réelle n'est utilisée.
